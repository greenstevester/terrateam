# CLAUDE.md - Build System (PDS/Make)

This file provides guidance for Claude Code when working with Terrateam's build system architecture.

## Build System Overview

Terrateam uses a sophisticated **PDS (Package Description System)** build architecture that manages 193+ OCaml modules with precise dependency tracking and multi-target compilation.

## Architecture Components

### 1. **PDS (Package Description System)**
- **Version**: 6.54 (custom build system)
- **Purpose**: Declarative OCaml package management and build coordination
- **Configuration**: `pds.conf` - defines all modules, dependencies, and build rules
- **Output**: Generates Makefile fragments and dependency graphs

### 2. **GNU Make Layer**
- **Main File**: `code/Makefile`
- **Purpose**: High-level build orchestration and code generation
- **Integration**: Includes PDS-generated `pds.mk` for module builds
- **Targets**: Development, testing, release, and schema generation

### 3. **HLL (High Level Language) Integration**
- **Configuration**: `hll.conf` - project metadata and dependency mapping
- **Dependency Management**: `hll.pins` - exact version pinning for reproducibility
- **Build Deps**: `merlin-of-pds`, `fmt` for IDE integration and formatting

### 4. **Opam Integration**
- **Custom Repository**: `opam/` directory with custom packages
- **Package Variants**: Multiple PDS versions (3.0.2, 5.31, 6.54)
- **Dependency Resolution**: Integration with opam ecosystem

## Build Configuration Files

### Core Configuration

#### **`pds.conf`** - Module Definition
```toml
[global]
selector = ["opam", "config", "var", "os"]

[global.debug]
extra_compiler_opts = "-g -bin-annot -strict-sequence -strict-formats -safe-string -w '@d@f@p@u@s@40+K@L@R'"

[global.release]  
extra_compiler_opts = "-bin-annot -strict-sequence -strict-formats -safe-string -noassert -w '+d+f+p+u+s+40+K+L+R'"

# 193+ module definitions with dependencies
[src.abb]
install = true
deps = ["abb_intf", "abb_scheduler_select"]

[src.terrat_oss]
type = "exec"
deps = ["terrat", "brtl", "abb_tcp_server", ...]
```

#### **`hll.conf`** - Project Metadata
```toml
pds = {major_version = 6}
desc = "Monorepo"
maintainer = "malcolm.matalka@acsl.se"

[deps_map]
"dns-client" = ["dns-client.resolvconf"]
containers = ["containers.data", "containers.bencode"]
ctypes-foreign = ["ctypes.foreign"]
```

#### **`hll.pins`** - Exact Versions
```
ISO8601 = "0.2.6"
containers = "3.12"
cohttp = "5.3.1"
# ... 53 pinned dependencies
```

### Generated Files

#### **`pds.mk`** - Auto-generated Build Rules
- Generated by `pds -d` command
- Contains make targets for each module
- Includes dependency resolution and build order
- **Never edit manually** - regenerated on each build

#### **Dune Compatibility**
```bash
# Generated for IDE compatibility
dune
dune-project  
dune-workspace
.merlin        # IDE integration via merlin-of-pds
```

## Development Commands

### Core Build Commands

```bash
cd code/

# Generate build configuration
pds -d                    # Generate pds.mk
pds -f | merlin-of-pds > .merlin   # IDE integration

# Build all components
make all                  # Generate .merlin + IDE setup
make release-terrat       # Build production binaries
make debug-terrat         # Build debug binaries
make test-terrat          # Run all tests

# Build specific targets
make release_terrat_oss   # OSS binary only
make release_terrat_ee    # Enterprise binary only
make release_iris         # Frontend only
```

## Build System Architecture

### Module Dependency Graph

```
193+ OCaml Modules
├── abb_* (Application Building Blocks)
│   ├── abb              # Core async runtime
│   ├── abb_io           # I/O operations  
│   ├── abb_curl         # HTTP client
│   └── abb_tcp_server   # TCP server
├── brtl_* (Web Framework)
│   ├── brtl             # Core web framework
│   ├── brtl_mw_*        # Middleware components
│   └── brtl_static      # Static file serving
├── terrat_* (Domain Logic)
│   ├── terrat           # Main application
│   ├── terrat_config    # Configuration
│   ├── terrat_vcs_*     # VCS integrations
│   └── terrat_tag_query # Query language
└── External Dependencies (53 packages)
    ├── containers 3.12  # Data structures
    ├── cohttp 5.3.1     # HTTP library
    └── yojson 2.2.2     # JSON processing
```

### Build Phases

1. **Dependency Resolution**
   - PDS reads `pds.conf` and generates dependency graph
   - Validates all dependencies are available
   - Determines build order based on dependencies

2. **Module Compilation**
   - Each module compiled independently with precise dependencies
   - Platform-specific compilation (FreeBSD/Linux/macOS)
   - Debug vs Release compilation flags

3. **Linking Phase**  
   - Executables linked with required modules
   - Different executables include different module sets
   - Static linking for deployment

4. **Code Generation**
   - OpenAPI clients generated from schemas
   - JSON Schema validation code
   - Web UI assets built and integrated

## Platform-Specific Builds

### Conditional Dependencies

```toml
# Base configuration
[src.abb]
deps = ["abb_intf", "abb_scheduler_select"]

# Platform-specific overrides
[src.abb.selector.freebsd]
deps = ["abb_intf", "abb_scheduler_kqueue"]

[src.abb.selector.linux]  
deps = ["abb_intf", "abb_scheduler_kqueue"]
```

### Compilation Flags

```toml
# Debug builds
[global.debug]
extra_compiler_opts = "-g -bin-annot -strict-sequence -strict-formats -safe-string"

# Release builds  
[global.release]
extra_compiler_opts = "-bin-annot -strict-sequence -strict-formats -safe-string -noassert"
```

## Build Optimization

### Parallel Builds
```bash
# Utilize all CPU cores
make -j$(nproc) release-terrat

# PDS supports parallel module compilation
pds -j$(nproc)
```

### Build Caching
- **PDS Cache**: Incremental compilation of unchanged modules
- **Opam Cache**: Dependency compilation cached
- **Docker Cache**: Multi-stage build layer caching

### Dependency Management
- **Exact Pinning**: `hll.pins` ensures reproducible builds
- **Custom Opam Repo**: Local packages override upstream versions
- **Selective Updates**: Pin only critical dependencies

## Troubleshooting

### Common Build Issues

1. **Missing Dependencies**
   ```bash
   # Regenerate dependency graph
   pds -d
   
   # Check opam environment
   eval $(opam env)
   ```

2. **Stale Generated Files**
   ```bash
   # Clean and regenerate
   make clean
   pds -c
   make all
   ```

3. **Platform Issues**
   ```bash
   # Check platform selector
   opam config var os
   
   # Force platform-specific build
   pds -d --selector linux
   ```

### Debug Build System

```bash
# Verbose PDS output
pds -d -v

# Debug make execution
make -d release-terrat

# Check generated makefile
less pds.mk
```

### Custom Build Targets


```toml
# Add new module to pds.conf

install = true
```

### Cross-Compilation

```bash

opam switch create 5.3.0+musl
eval $(opam env)

```
